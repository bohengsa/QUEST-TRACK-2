# week-03 계획서 · 내 캐릭터 데스크톱 펫

## 만들 것
- 화면 오른쪽 아래 구석에 앉아 있는 작은 펫 프로그램
- 펫은 하얀 강아지이고, 앞에 작은 키보드가 놓여 있다
- 키보드를 누를 때마다 강아지가 앞발로 키보드를 번갈아 누른다
- 한동안 키를 안 누르면 꾸벅꾸벅 존다
- 그림은 2×2 네 칸 그림 한 장(`art/sheet.png`, 1254×1254)을 잘라서 쓴다

| 칸 | 위치 | 언제 보여 주나 |
|---|---|---|
| ① 두 앞발 듦 | 왼쪽 위 | 기다릴 때 (키를 뗀 뒤 잠깐 지나면) |
| ② 왼발 누름 | 오른쪽 위 | 키를 누를 때 (번갈아, 홀수 번째) |
| ③ 오른발 누름 | 왼쪽 아래 | 키를 누를 때 (번갈아, 짝수 번째) |
| ④ 졸기 | 오른쪽 아래 | 10초 동안 키를 안 누르면 |

### 정한 것
- 그림: 내가 따로 구해 왔고 `week-03/art/sheet.png` 에 넣었다. 원본 파일은 고치지 않고, 위치 맞추기는 자를 때 코드로 한다.
- 움직임: 어떤 키든 누를 때마다 ② → ③ → ② → ③ 번갈아. (키 종류를 보지 않으려고 왼쪽/오른쪽 구분은 안 하기로 함)
- 위치·크기: 오른쪽 아래, 작업 표시줄 바로 위, 약 150×150 픽셀. 마우스로 끌어서 옮길 수 있다.
- 아래는 Claude 가 먼저 정하고, 내가 다시 질문받아 확정함
  - 키를 뗀 뒤 0.1초가 지나면 ① 로 돌아간다. (내가 다시 정함)
  - 10초 동안 안 누르면 ④ 졸기. 아무 키나 누르면 바로 깬다. (내가 다시 정함)
  - 배경 투명, 테두리 없음, 항상 다른 창 위에, 작업 표시줄에는 안 보임.
  - 펫을 오른쪽 클릭하면 메뉴: "오늘 누른 횟수: N번" 표시, "끄기". (내가 다시 정함)
  - 누른 횟수는 화면에만 보이고 파일에 저장하지 않는다. 끄면 0부터 다시.
  - 마지막에 PyInstaller 로 더블클릭해서 켜는 exe 파일 하나로 묶는다. (내가 다시 정함)

## 어디서 돌아가는지
- 내 컴퓨터: Windows 11
- Python 3.12 로 만든다. (이 컴퓨터에 3.15 도 있지만 PySide6·PyInstaller 가 아직 3.15 를 지원하지 않을 수 있어서, 이미 깔려 있는 3.12 를 쓴다)
- `week-03/.venv` 가상환경 안에 패키지를 설치한다. 컴퓨터 전체에는 설치하지 않는다.
- 인터넷 연결 없이 돌아간다.

## 단계
- "확인할 것"은 모두 예 · 아니오로 답하는 질문이다. 전부 "예"면 그 단계를 커밋하고, 하나라도 "아니오"면 고친 뒤 다시 확인한다.

### 1단계 · 준비
- Python 3.12 로 `week-03/.venv` 를 만들고 재료 4개를 설치한다. (설치 전에 나한테 묻기)
- `requirements.txt`, `.gitignore` 를 만든다.
- **확인할 것:**
  - 4개 패키지를 불러오는(import) 명령을 실행하면 오류 없이 끝나는가?
  - `git status` 를 쳤을 때 `.venv` 가 목록에 없는가?
- **커밋:** `week-03: 1단계 준비 (requirements, gitignore)`

### 2단계 · 그림 자르고 맞추기
- `pet.py` 에 Pillow 로 `sheet.png` 를 네 칸(627×627)으로 자르는 부분을 만든다.
- 칸마다 키보드 위치를 찾아서, 네 칸의 키보드가 같은 자리에 오도록 그림을 위아래·좌우로 옮겨 맞춘다. (④ 졸기 칸이 조금 아래에 그려져 있어 보임)
- 확인용으로 잘린 네 장을 `week-03/check/` 에 저장해서 열어 본다. (`check/` 는 커밋하지 않는다)
- **확인할 것:**
  - 잘린 그림 네 장을 열어 보면 ①②③④ 순서와 그림이 맞는가?
  - 잘린 그림의 배경이 투명한가? (흰색이나 검은색 칸이 없는가?)
  - 네 장을 번갈아 넘겨 보면 키보드가 움직이지 않고 제자리에 있는가?
  - 그림 가장자리에 옆 칸 그림이 조금이라도 삐져나오지 않는가?
  - `git status` 를 쳤을 때 `check` 가 목록에 없는가?
- **커밋:** `week-03: 2단계 펫 그림과 네 칸 자르기` (`art/sheet.png` 도 같이 커밋)

### 3단계 · 펫 창 띄우기
- PySide6 로 투명·테두리 없음·항상 위 창을 오른쪽 아래에 150×150 으로 띄우고 ① 을 보여 준다.
- **확인할 것:**
  - 펫 주변으로 바탕 화면이 비쳐 보이는가?
  - 펫이 작업 표시줄을 가리지 않는가?
  - 다른 창을 클릭해도 펫이 그 창 위에 남아 있는가?
  - 작업 표시줄에 펫 아이콘이 안 보이는가?
  - 150×150 크기에서 강아지의 앞발과 눈이 알아볼 수 있게 보이는가?
- **커밋:** `week-03: 3단계 펫 창 띄우기`

### 4단계 · 끌어서 옮기기와 메뉴
- 마우스로 끌면 펫이 따라 움직인다.
- 오른쪽 클릭 메뉴에 "오늘 누른 횟수"와 "끄기"를 넣는다.
- **확인할 것:**
  - 펫을 마우스로 끌면 놓은 자리로 옮겨지는가?
  - 오른쪽 클릭하면 "오늘 누른 횟수"와 "끄기"가 있는 메뉴가 뜨는가?
  - "끄기"를 누른 뒤 작업 관리자에 펫(python)이 남아 있지 않은가?
- **커밋:** `week-03: 4단계 끌어서 옮기기, 메뉴`

### 5단계 · 키에 맞춰 누르기
- pynput 으로 키 누름을 듣고, 누를 때마다 횟수 +1, 그림 ② ↔ ③ 번갈아. 0.1초 지나면 ①.
- 어떤 키인지는 받자마자 버린다. 변수에 담지도, 화면이나 파일에 찍지도 않는다.
- **확인할 것:**
  - 메모장에 타자를 치면 펫이 ② ③ 을 번갈아 보여 주는가?
  - 타자를 멈추면 펫이 곧바로 ① 로 돌아가는가?
  - 브라우저 같은 다른 창에서 쳐도 펫이 움직이는가?
  - 글자 10개를 친 뒤 메뉴를 보면 횟수가 10 늘어 있는가?
  - `pet.py` 에서 키 이름을 저장하거나 화면·파일에 찍는 줄이 하나도 없는가?
- **커밋:** `week-03: 5단계 타자에 맞춰 움직이기`

### 6단계 · 졸기
- 10초 동안 안 누르면 ④, 누르면 바로 깨서 ② 또는 ③.
- **확인할 것:**
  - 키를 안 누르고 10초 기다리면 ④ 졸기 그림이 되는가?
  - 졸고 있을 때 키 하나를 누르면 바로 ② 나 ③ 으로 바뀌는가?
- **커밋:** `week-03: 6단계 졸기`

### 7단계 · exe 로 묶기
- PyInstaller 로 `pet.exe` 하나를 만든다. 그림도 exe 안에 넣는다. 검은 콘솔 창은 안 뜨게 한다.
- **확인할 것:**
  - 백신이 `pet.exe` 를 막지 않는가? (아니오면 멈추고 나한테 알리기. 키를 듣는 프로그램이라 의심받을 수 있음)
  - `dist/pet.exe` 를 더블클릭하면 펫이 뜨는가?
  - 검은 콘솔 창이 안 뜨는가?
  - 가상환경을 켜지 않은 새 PowerShell 에서 실행해도 켜지는가?
  - `git status` 를 쳤을 때 `build`, `dist` 가 목록에 없는가?
- **커밋:** `week-03: 7단계 exe 만들기 설정` (exe 파일 자체는 커밋하지 않는다)

## 하지 말 것
- 어떤 키를 눌렀는지는 저장도 전송도 하지 않고, 몇 번 눌렀는지만 센다.
- 어떤 키를 눌렀는지 화면에 띄우거나 로그로 남기지도 않는다.
- 누른 횟수도 파일에 저장하지 않는다.
- 인터넷에 연결하는 코드를 넣지 않는다.
- 패키지를 컴퓨터 전체에 설치하지 않는다. 설치 전에는 꼭 묻는다.
- `.venv`, `build`, `dist`, `check`, exe 파일은 커밋하지 않는다.
- `art/sheet.png` 원본은 고치거나 덮어쓰지 않는다.
- `week-03` 밖의 파일은 건드리지 않는다.
- 한 번에 여러 단계를 하지 않는다. 한 단계 끝나면 확인 → 커밋 → 다음 단계.
- GitHub 에 올리는(push) 건 내가 하자고 할 때만.
